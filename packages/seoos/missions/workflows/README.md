# Missions

One folder per desk, matching `agents/roster/`. The loader walks the tree.

```
shared/    onboard_site           runs once, before any desk has work
search/    monthly_audit, weekly_growth_cycle, fix_and_publish,
           content_production, link_building, local_cycle, aeo_tracking
content/   content_discovery, content_engine, content_amplify
```

`content_production` sits under `search/` rather than `content/` on purpose.
It is the keyword-led production queue the head of search commissions from
measured gaps. `content_engine` under `content/` is the argument-led one the
content director commissions from an approved point of view. Both end at the
same writer and the same review queue, which is the point.

A discovery mission gates its desk. `content_discovery` has to finish and be
approved before `content_engine` runs, because production quality applied to
the wrong idea is the most expensive failure in this business and the easiest
one to make.
